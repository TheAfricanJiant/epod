The ESP32-C3 reads MP3 or WAV audio chunks from the MicroSD card using standard SPI protocols (SD.h library).

Energy-Efficient BLE File & Command Transfer
Sending large audio files over pure BLE standard profiles can be slow. Use a hybrid BLE transfer strategy:

Control & Metadata Mode (BLE GATT): Use BLE for UI navigation (Play/Pause, Volume, Track info sync to mobile app).

Fast Song Sync Mode (BLE-Triggered Chunking):

The app breaks down .mp3 tracks into 256-byte binary chunks and streams them over a custom BLE NUS (Nordic UART Service) protocol directly into the ESP32-C3 buffer, which writes the data straight to the MicroSD file system.

Alternative High-Speed Option: The app uses BLE to send a fast signal that temporarily turns on the ESP32-C3 Wi-Fi Soft-AP for 30 seconds to upload files via a local web interface, then immediately turns Wi-Fi off to stay strictly on BLE low-power mode.
